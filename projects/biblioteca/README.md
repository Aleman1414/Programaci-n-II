# Proyecto ejemplo: Biblioteca (POO + GUI + JSON)

Este proyecto está pensado para explicar **Programación II en Python** con enfoque en:

- POO (clases, objetos, encapsulación con `@property`, herencia, composición)
- Estructuras de almacenamiento (listas, búsqueda, modificación)
- Excepciones (validación y reglas de negocio)
- GUI con **Tkinter** (formularios, `ttk.Treeview`, eventos, `messagebox`)
- Persistencia simple con **JSON** (stdlib)

## Ejecutar

Desde la raíz del repo:

```bash
python3 projects/biblioteca/app.py
```

Los datos se guardan en `projects/biblioteca/data/libros.json`.
